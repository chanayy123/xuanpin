# THunt 销量字段口径调查与 20 商品详情补采

调查对象限定为 `makeup bag` 与 `cosmetic bag` 当前页共同出现、但 THunt 插件“销量”不一致的 20 个 Temu 商品 ID。逐商品原值与访问结果在 [`normalized/sales_audit_20.json`](normalized/sales_audit_20.json)，浏览器直接取得的表格行和详情摘录在 `raw/`。这些是 2026-09-23 当次页面快照，不代表历史完整销量。

## 字段口径与已验证事实

- THunt 插件搜索表格仅显示“销量”和“销售额”，没有在该表格标明日、周、月、总的时间窗，也没有给出计算来源或地区口径。两个关键词中同一商品 ID 的“销量”在全部 20 个共有商品上不一致；原始表格是上级目录的 `raw/thunt_makeup_bag_drawer.html` 和 `raw/thunt_cosmetic_bag_drawer.html`。
- THunt 网站的[商品数据页](https://thunt.ai/cn/product-database)把“销量”分为“日、周、月、总”四列；本次已保存列表表头和按商品 ID 查询的结果。其[插件说明](https://thunt.ai/plugin-cn/temu-product-analysis-tool)使用“总销量”一词，[首页 FAQ](https://thunt.ai/cn)说热门商品及销量历史每日更新，但没有说明插件搜索表格的“销量”是否等于网站“总销量”、具体数据来源、地区、商品与规格聚合方式、更新时间或回溯修正规则。因此不能自行把插件字段定义成网站“总销量”。
- 20 个商品中，THunt 网站默认筛选下按 ID 查询有 11 个结果，9 个未返回。11 个网站“总销量”中，仅 1 个恰好等于插件 `makeup bag` 值，3 个恰好等于插件 `cosmetic bag` 值，其余 7 个与两边都不相同。这不是同一口径已验证的证据。
- THunt 完整详情页仅取得 3 个。页面显示过当日剩余详情次数 2、随后 1；其余 17 个没有使用完整详情页补齐。页面上的“已下架”标签也未直接当作 Temu 实时状态。
- 80 条插件表格记录的“销售额”与同一行 `价格 × 销量` 全部相差不超过 10%，其中 62 条相差不超过 1%。它与“销量”不是独立交叉验证；是否由 THunt 直接相乘生成，页面没有明示。

## 详情补采覆盖与数据使用边界

`normalized/sales_audit_20.json` 对 20 个 ID 都保留两词插件原值、THunt 网站查询状态、THunt 详情状态、Temu 详情状态和对应证据路径。Temu 商品详情中的“已售”只在主商品信息区提取；已售罄页下方相似商品的“已售”数字不归给目标商品。已售罄记录为状态，**不写成销量 0**。

Temu 详情页目前已得到 6 个主商品销量、8 个已售罄状态；第 15 个商品再次出现安全验证后停止访问，另有 4 个尚未访问、1 个在原映射中缺少 URL。用户手动完成验证后再继续其余商品。

本次调查支持把插件 `sales.raw` 保留为来源显示值，但**不支持用它在多个关键词或多个品类之间做可比的总销量、Top 商品销量占比、真实订单量或销售额推断**。原报告里的销量中位数及 Top 5/Top 10 占比只是对选择的一列显示数字做的算术统计，不应用于跨品类决策。价格与评论字段的统计可单独使用，但仍受当前页 40 条样本范围限制。

下一步需要 THunt 官方明确插件“销量”的时间窗、地区、商品 ID 与规格聚合口径及更新规则，并用同一时间的两个关键词搜索页和详情页重复核验。调查期间未扩大品类、未绕过安全验证。
